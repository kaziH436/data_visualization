## Kernel Density Estimation (KDE)
A Probability Density Function (PDF) is the true, theoretical mathematical function describing the likelihood of a continuous random variable falling within a given range, whereas Kernel Density Estimation (KDE) is a practical,
data-driven method used to estimate that unknown PDF from a finite sample of data

## Probability Density Function (PDF)
A probability density function (PDF) does not find the probability of a single exact value for a continuous variable; instead, it finds the probability of the variable falling within a range of values
